Comment ajouter un circuit

En 4 étapes

  1. Dessinez le circuit ici (ou chargez un exemple dans la liste en haut).
  2. Cliquez Télécharger le .trk et placez le fichier dans le dossier tracks/ du projet. Le début du nom fixe l'ordre dans le menu : 06_mon_circuit.trk.
  3. Lancez python tools/gen_tracks.py (il met à jour tracks_data.cpp et le nombre de circuits).
  4. Compilez comme d'habitude (idf.py build). Maximum : 16 circuits.

Les commandes

CommandeEffet
straight LONG [PENTE]ligne droite (entrée + milieu + sortie de même longueur), avec une pente facultative
curve LONG COURBE [PENTE]virage : la courbure monte, se maintient, puis redescend
road ENTRÉE MAINTIEN SORTIE COURBE [PENTE]la commande complète : trois longueurs séparées
scurves COURBEsérie de 5 virages en S
bumpssérie de petites bosses
downhill LONGdescente douce qui ramène la route au niveau 0

Les valeurs

TypeNomsOu un nombre
Longueur (segments)SHORT=25, MEDIUM=50, LONG=1000 à 400
CourbureEASY=2, MED=4, HARD=6−12 à 12 (positif = vers la droite, négatif = vers la gauche : -HARD)
Pente (hauteur gagnée)LOW=20, MED=40, HIGH=60−200 à 200 (négatif = descente : -MED)

Règles pour un bon circuit

  • Commencez et finissez par une ligne droite d'au moins 25 segments : la grille de départ s'y trouve.
  • Une pente est un gain d’altitude durable : pour une bosse, montez puis redescendez. Terminez à altitude 0 (au-delà de 20 unités d’écart, le jeu ajoute une descente automatique).
  • Visez 2 300 à 3 000 segments, soit 45 à 55 s par tour.
  • Les virages HARD sont des épingles : on y freine. Alternez avec des lignes droites.
  • Les premiers virages doivent rester faciles : le départ se joue à huit voitures.
